# ape2_l: the factory gorilla test (archived 2026-10-12)

Preston: "Was a good test but our ape is still better than the mass produced one." Four rounds through the creature
factory (kit parts, plate_on, quad_rig, factory palette). Best round v4: outline overlap with Preston's master 0.585
(ape_l 0.534 on the same measure, but ape_l reads far better by eye: its 43 passes of modelling detail are the
difference). Kept here for the record: build script, palette, sprites v1-v4, blend, comparison sheets. Not in the game.
Lesson for the factory: the shared path (rig, palette, measures) carries a machine; the modelling detail still has
to be built per machine, and the gorilla's own recipe is the better template for it.
