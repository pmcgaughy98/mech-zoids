## Open an editable model

Open `art/model_catalog/workspaces/<id>.blend` in Blender 5.2. For example, `gorilla.blend`. Or run from this project:

```powershell
./tools/open_mech_workbench.ps1 gorilla
```

Each native workspace contains the original full-detail static mesh in **01 WORKING MODEL**, four packed white source sheets on visible boards in **02 FOUR SOURCE SHEETS**, a neutral studio, and a **START HERE** text block. The reference boards are locked against accidental selection. Select the working mesh and use Tab for mesh editing; Numpad period frames it. Orbit to inspect it. Any Image Editor can show the packed front, left, back or right image at full size for close eye/socket comparison.

The four boards are a side-by-side reference desk, not calibrated orthographic overlays. Working-root scale and placement are for this desk only. Model-forward orientation, proportions and production game scale still need deliberate review.

## Source of truth

- `art/model_catalog/catalog.json`: exact IDs, source filenames, SHA256 hashes, four reference paths per entry, and hash-matched original project take paths. The eel uses the tighter Hunyuan uploads from `take-b-level`, not its older upload sheets.
- `art/model_catalog/sources/`: byte-identical downloaded GLBs, original names retained. Do not overwrite. `.gdignore` prevents importing the high-detail archive twice.
- `art/model_catalog/references/<id>/`: exact downloaded generation sheets, unchanged. All four sheets were hash-matched to the original project files.
- `art/model_catalog/workspaces/`: editable native Blender files, full-detail geometry and packed images. Work here or in a clearly named revision copied from here.
- `art/model_catalog/display/`: reduced 40k-triangle / up-to-1K texture copies for viewing the whole fleet together. These are gallery proxies, not artist sources or approved production optimization.

## Artist review loop

1. Read the selected entry and its four sheets. Check limb count, joints and attachment points, silhouette, left/right consistency, and front/back armor before making style changes.
2. Inspect the eyes close up from several angles: socket shape, rim depth, actual lens geometry and placement. A dark painted patch is not automatically a correct socket or eye.
3. Fix geometry in a working revision. Preserve UV/material intent where possible. Record which reference resolves a conflict; ask Preston when the four images disagree.
4. Compare the repaired mesh against all four sheets and at the real match camera. Show inspected evidence before claiming a repair. Materials alone do not establish repaired anatomy.
5. Export a versioned GLB for review and explicitly update the catalog's display path only after the replacement is verified. Keep the archive intact. Do not replace gameplay assets or another lane's work without scope for that integration.

Workspace setup has not repaired limbs, eyes, sockets, topology or rigs. Every working source begins **unre
