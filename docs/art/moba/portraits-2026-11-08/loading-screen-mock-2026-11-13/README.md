# Loading screen visual concept

Standalone mockup using the existing new card masters. Open index.html. No game scene or gameplay changed. Two opposing five-pilot rows, readable mech labels, individual readiness, shared loading progress, cyan/ember team accents. Pilot names and percentages are example content. Mirror picks illustrate a ten-player lineup from the eight available new cards.

Fennec retained provisionally at Preston's direction; no skill names or kit claims appear on the screen. Kit changes can replace artwork without changing this layout. Full-resolution masters remain unchanged; inline conversation preview uses compressed display copies. The ornate Fennec gate frame is provisional scene art.

Current project has a 320x180 internal viewport. This concept targets a separate high-resolution loading UI canvas; a direct downscale would not preserve the typography. Implementation requires confirming the match-loading lifecycle. No live screen was installed by this visual concept.

Validation: rendered and visually inspected the standalone mockup at 1920x1080 in headless Edge. Both five-player rows, all mech labels, readiness bars and footer fit without clipping. All eight source images exist. Inline preview is below 1 MB. Narrow layout reflows to three/two columns; not a separate proposed in-game mobile layout.
