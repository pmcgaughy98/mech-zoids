## Method

One new four-view modeling reference per creature using the built-in image tool and craft-only reference, then four separate white modeling inputs as Preston requested for the bison. Save the prompt, unchanged raw, provenance, measurements and honest visual gaps. No automatic paid redos. No assumption that design approval also approves final kit numbers, a new fal charge or game installation. Actual built-in image token/cost figures are not exposed. No commits unless asked.
