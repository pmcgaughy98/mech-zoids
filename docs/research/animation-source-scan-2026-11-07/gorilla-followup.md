## Match to our gorilla

Proposed donor choices, not approved kit/timing changes:
- Chest Beat Roar: chest-beat body reference; shield/reactor motion as separate rigid tracks.
- Furious Slam / Rage Smash / Swing Smash: gather and shoulder-weight reference for heavy impact or dome deployment.
- Wild Strikes / Swing Down: candidate basic-strike source; edit to one contact event rather than retaining a long cinematic sequence.
- Shove Forward: braced shield-pressure posture reference, not an existing shield animation.
- Agitated Idle / Heavy Breath Idle: restrained guarded/charged idle candidates.
- Use the separate Locomotion collection to evaluate continuous knuckle-walking. Expressive alert-walk actions in Aggressions are not automatically clean looping gait clips.

## Suggested practical test

The $12 pack is the clearest small whole-body donor evaluation. A $2.50 Chest Beat Roar or Furious Slam clip is a smaller alternative for testing the gorilla's signature motion. Using both would still require separate rig mappings.

No gorilla GLB/FBX/BLEND was found under the checked ape art and scratch model folders. Those locations contain only the Fox/RobotExpressive benchmarks and existing rhino experiments; this is not a search of every personal download directory.

A real test needs knuckle contact without wrist penetration, rigid shield/armor hardware, shoulder limits, one contact event with the kit's recovery-cancel contract, and all directions rendered at one 35-degree camera/scale. No successful retarget or game integration is claimed.
